# **Refugio de Dragones**

La Asociación Arcana Internacional te ha encargado desarrollar un pequeño sistema informático para gestionar un **refugio de dragones**.

Los **dragones** son famosos por su capacidad de expulsar fuego con mayor o menor intensidad. Se necesita conocer el nombre, la edad y su nivel de fuego (0-10). El dragón debe también poder realizar su movimiento, que consiste en lanzar una llamarada, que se representará con un mensaje:

El dragón (NOMBRE) ha lanzado una llamarada de nivel (NIVELFUEGO).

Además, el refugio necesita una **guarida mágica**. Esta guarida tiene un **espacio limitado**, por lo que el sistema debe permitir **añadir nuevos dragones mientras haya espacio disponible**, y debe ofrecer la posibilidad de consultar cuántas plazas disponibles hay, o mostrar de forma clara qué dragones se encuentran actualmente dentro al imprimir el objeto que representa la guarida.

Finalmente, será necesario comparar dragones para determinar si dos de ellos deben considerarse iguales según sus características esenciales (nombre y edad), así como generar descripciones legibles de cada dragón para mostrarlas por pantalla al imprimir dicho objeto.

Tu misión consiste en diseñar y programar todos los elementos necesarios para:

1. Representar adecuadamente la información de un dragón.

2. Permitir que la guarida almacene varios dragones y pueda mostrar su contenido.

3. Hacer que un dragón pueda lanzar una llamarada, mostrando el correspondiente mensaje.

4. Comparar dragones y mostrar sus datos de manera legible cuando sea necesario.
